# Orbio hero sections

Four website hero sections for Orbio: Home, Launchpad, Protocol and Incognito.

## Open
Open `index.html` in a browser, or open one hero directly:
`home.html`, `launchpad.html`, `protocol.html`, `incognito.html`.
Switch heroes from the navbar. The Marble/Void switch sits bottom-right.

Keys: `H` hides the controls (for screen recording).

Move the cursor over a hero to wake the bit field.

Static files, no build step. Fonts load from Google Fonts (Geist, Geist Mono).

The headlines and wordmark are outlined from ABC Arizona Flare (Dinamo trial).
License it before production use.
